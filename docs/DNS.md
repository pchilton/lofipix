## Domain Names

- `api.lofipix.app` - VPS hosting API
- `storage.lofipix.app` - MinIO
- `www.lofipix.app` - Web App (Cloudflare Pages)
- `pwa.lofipix.app` - PWA App (Cloudflare Pages)
- `lofipix.app` - Redirect to www
